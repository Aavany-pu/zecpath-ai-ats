# Zecpath AI

## AI-Powered Recruitment System

Zecpath AI is an AI-based recruitment project designed to support
candidate processing and evaluation across multiple stages of the
hiring workflow.

## Project Workflow

Candidate Resume
        ↓
Resume Processing
        ↓
ATS Scoring
        ↓
Candidate Screening
        ↓
HR Interview Evaluation
        ↓
Technical Skill Evaluation
        ↓
Decision & Recommendation
        ↓
Hiring Intelligence Report
        ↓
Recruiter Output

## Main Project Areas

- Resume Processing
- ATS Scoring
- Candidate Screening
- HR Interview Evaluation
- Technical Skill Evaluation
- Decision and Recommendation
- Hiring Intelligence
- Recruiter-Facing Outputs
- Documentation
- Internal Review
- Feature Enhancements
- Final Optimization
- Presentation
- Mock Demo
